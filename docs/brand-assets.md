# Community illustration brand assets

The server scene uses twelve actual project marks appearing in
`src/assets/community-original.jpg`. They identify technologies discussed by the
community; they do not imply sponsorship or a partnership.

Assets are self-hosted SVGs with no scripts, embedded HTML or remote resource
references. Simple Icons paths are unchanged; `fill="currentColor"` was added to
their root elements so the application can render monochrome marks. The scene's
accent colors are adjusted for its dark background. The vLLM compact mark retains
its original geometry and colors.
